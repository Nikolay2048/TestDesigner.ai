# Постановка 5. Возврат автомобиля с небольшим повреждением

Цель: клиент возвращает автомобиль с новой царапиной, сотрудник регистрирует инцидент, а система закрывает аренду с отметкой о проверке.

## Зависимость

Сценарий зависит от активной аренды из сценария 1, 2 или 3. Если сценарий запускается отдельно, сначала нужно создать бронирование, оплатить его и выполнить выдачу.

## Шаги сценария

1. Пользователь имеет активную аренду и открывает её текущее состояние.
2. Сотрудник фиксирует возврат автомобиля с корректным пробегом, но с повреждением кузова.
3. Сотрудник регистрирует инцидент по аренде и описывает царапину.
4. Пользователь повторно открывает аренду и видит, что по ней есть признак зарегистрированного инцидента.
5. Система закрывает аренду как требующую проверки.

## Ожидаемый бизнес-результат

Возврат принимается, инцидент зарегистрирован, аренда не считается полностью беспроблемной и требует последующей проверки.

## Специальная проверка для стабилизации

В постановке порядок шагов указан как возврат, затем регистрация инцидента. Мок-сервер допускает регистрацию инцидента только до закрытия аренды. Если выполнить шаги строго по постановке, сервер вернёт ошибку и подсказку изменить порядок действий.
