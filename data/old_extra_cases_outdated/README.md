# Carsharing synthetic documentation dataset

Синтетический набор документации для ИИ-проекта автоматизации тест-дизайна.

Структура:
- 15 папок сценариев `case_001...case_015`
- в каждой папке:
  - `01_business_requirements.md`
  - `02_system_analysis.md`
  - `03_openapi.yaml`
  - `04_flk_rules.yaml`
  - `05_status_transition_matrix.yaml`

Основной файл для генерации тест-дизайна: `02_system_analysis.md`.

Внимание: документация синтетическая. В текстах намеренно оставлен небольшой “человеческий шум”: неодинаковые термины, уточнения, неоднозначности и конфигурационные параметры.
