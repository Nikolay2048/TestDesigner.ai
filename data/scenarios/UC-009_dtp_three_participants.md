UC-009. ДТП с тремя участниками и двумя страховыми делами
Название сценария

Регистрация ДТП с одним виновником и двумя пострадавшими, оформление отдельных страховых дел для каждого пострадавшего и проведение выплат по каждому делу.

1. Бизнес-контекст

В одном ДТП может участвовать несколько транспортных средств и несколько пострадавших. Каждый пострадавший имеет право оформить отдельное страховое дело, пройти независимую экспертизу ущерба и получить отдельную страховую выплату.

Данный сценарий проверяет, что система корректно ведёт несколько связанных страховых процессов внутри одного ДТП и не смешивает данные разных пострадавших.

2. Участники сценария
Участник	Описание
Виновник ДТП	Участник, несущий полную ответственность за происшествие
Первый пострадавший	Участник, оформляющий первое страховое дело
Второй пострадавший	Участник, оформляющий второе страховое дело
Оператор ДТП	Регистрирует происшествие, участников и транспортные средства
Эксперт	Проводит оценку ущерба по каждому делу
Страховая система	Создаёт и подтверждает выплаты

3. Предусловия

Сервис ДТП доступен.
Система поддерживает регистрацию нескольких участников в одном ДТП.
Для каждого пострадавшего можно создать отдельное страховое дело.
Экспертиза и выплата выполняются независимо по каждому страховому делу.

4. Основной поток сценария

Шаг 1. Регистрация ДТП

Endpoint: POST /v1/accidents

Оператор регистрирует ДТП с описанием обстоятельств и местом происшествия.

Результат шага:

создана запись о ДТП;
ДТП готово к добавлению участников.

Шаг 2. Добавление виновника

Endpoint: POST /v1/accidents/{accidentId}/participants

Оператор добавляет первого участника как виновника ДТП с полной долей ответственности.

Результат шага:

в ДТП зарегистрирован виновник;
доля вины виновника составляет 100%.

Шаг 3. Добавление первого пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/participants

Оператор добавляет второго участника как первого пострадавшего.

Результат шага:

в ДТП зарегистрирован первый пострадавший;
участник может быть заявителем по страховому делу.

Шаг 4. Добавление второго пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/participants

Оператор добавляет третьего участника как второго пострадавшего.

Результат шага:

в ДТП зарегистрирован второй пострадавший;
участник может быть заявителем по отдельному страховому делу.

Шаг 5. Фиксация транспортного средства виновника

Endpoint: POST /v1/accidents/{accidentId}/participants/{participantId}/vehicles

Оператор добавляет транспортное средство виновника и фиксирует повреждения.

Результат шага:

транспортное средство виновника связано с ДТП;
ущерб учтён в составе происшествия.

Шаг 6. Фиксация транспортного средства первого пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/participants/{participantId}/vehicles

Оператор добавляет транспортное средство первого пострадавшего и фиксирует повреждения.

Результат шага:

транспортное средство первого пострадавшего связано с ДТП;
ущерб доступен для страховой оценки.

Шаг 7. Фиксация транспортного средства второго пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/participants/{participantId}/vehicles

Оператор добавляет транспортное средство второго пострадавшего и фиксирует повреждения.

Результат шага:

транспортное средство второго пострадавшего связано с ДТП;
ущерб доступен для отдельной страховой оценки.

Шаг 8. Создание страхового дела первого пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/claims

Первый пострадавший инициирует страховое дело по своему ущербу.

Результат шага:

создано первое страховое дело;
дело связано с первым пострадавшим.

Шаг 9. Создание страхового дела второго пострадавшего

Endpoint: POST /v1/accidents/{accidentId}/claims

Второй пострадавший инициирует отдельное страховое дело по своему ущербу.

Результат шага:

создано второе страховое дело;
дело связано со вторым пострадавшим.

Шаг 10. Экспертиза по первому страховому делу

Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/assessments
Endpoint: PATCH /v1/accidents/{accidentId}/claims/{claimId}/assessments/{assessmentId}

Эксперт назначает и завершает оценку ущерба первого пострадавшего.

Результат шага:

экспертиза по первому делу завершена;
первое дело получает подтверждённую сумму ущерба.

Шаг 11. Экспертиза по второму страховому делу

Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/assessments
Endpoint: PATCH /v1/accidents/{accidentId}/claims/{claimId}/assessments/{assessmentId}

Эксперт назначает и завершает оценку ущерба второго пострадавшего.

Результат шага:

экспертиза по второму делу завершена;
второе дело получает подтверждённую сумму ущерба.

Шаг 12. Создание и подтверждение выплаты первому пострадавшему

Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/payments
Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/payments/{paymentId}/confirm

Страховая система создаёт и подтверждает выплату по первому страховому делу.

Результат шага:

выплата первому пострадавшему создана;
выплата подтверждена.

Шаг 13. Создание и подтверждение выплаты второму пострадавшему

Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/payments
Endpoint: POST /v1/accidents/{accidentId}/claims/{claimId}/payments/{paymentId}/confirm

Страховая система создаёт и подтверждает выплату по второму страховому делу.

Результат шага:

выплата второму пострадавшему создана;
выплата подтверждена.

Шаг 14. Проверка итогового состояния ДТП

Endpoint: GET /v1/accidents/{accidentId}

Оператор проверяет, что ДТП содержит всех участников, все транспортные средства и оба страховых дела.

Результат шага:

в системе отражены три участника ДТП;
оба страховых дела обработаны независимо;
итоговая информация по ДТП согласована с созданными делами и выплатами.

5. Постусловия

ДТП содержит одного виновника и двух пострадавших.
Для каждого пострадавшего создано отдельное страховое дело.
По каждому делу завершена экспертиза.
По каждому делу создана и подтверждена выплата.

6. Бизнес-правила

В одном ДТП может быть несколько пострадавших.
Каждое страховое дело относится к одному конкретному заявителю.
Экспертиза и выплата одного пострадавшего не должны изменять данные другого страхового дела.
Итоговый ущерб по ДТП должен учитывать повреждения всех связанных транспортных средств.
