# UC_102 — Поиск и просмотр объявлений

## Контекст

Покупатель хочет найти нужный товар. Он может отфильтровать объявления по категории, городу и диапазону цены. Поиск возвращает только опубликованные объявления. Найдя подходящее, покупатель открывает карточку и читает полное описание. При каждом открытии карточки счётчик просмотров объявления увеличивается на один. Идентификатор объявления из этого сценария передаётся в UC_103.

---

## Сценарий

### Шаг 1 — Поиск объявлений по фильтрам

`GET /api/bb/v1/ads`

В счастливом пути используется только фильтр по категории: category=static ELECTRONICS. Параметры city, priceMin, priceMax НЕ включаются в happy path (они опциональны и проверяются в отдельных тест-кейсах). Параметры page=static 1, pageSize=static 20. Авторизация не требуется. Система возвращает постраничный список опубликованных объявлений. Из ответа извлекается adId первого элемента: source_field=$.items[0].adId.

---

### Шаг 2 — Просмотр полной карточки объявления

`GET /api/bb/v1/ads/{adId}`

Покупатель открывает карточку выбранного объявления. Авторизация не требуется. Система возвращает полное содержимое: заголовок, подробное описание, цену, категорию, город, статус, количество просмотров, дату создания и дату публикации. При каждом обращении к этому endpoint счётчик просмотров данного объявления увеличивается на единицу. Из ответа извлекается adId.
