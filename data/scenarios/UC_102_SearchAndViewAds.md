# UC_102 — Поиск и просмотр объявлений

## Контекст

Покупатель хочет найти нужный товар. Он может отфильтровать объявления по категории, городу и диапазону цены. Поиск возвращает только опубликованные объявления. Найдя подходящее, покупатель открывает карточку и читает полное описание. При каждом открытии карточки счётчик просмотров объявления увеличивается на один. Идентификатор объявления из этого сценария передаётся в UC_103.

---

## Сценарий

### Шаг 1 — Поиск объявлений по фильтрам

`GET /api/bb/v1/ads`

Покупатель ищет объявления в категории ELECTRONICS, не задавая фильтры по городу и цене. Авторизация не требуется. Система возвращает постраничный список опубликованных объявлений — по двадцать позиций на первой странице. Покупатель выбирает первое объявление в списке.

---

### Шаг 2 — Просмотр полной карточки объявления

`GET /api/bb/v1/ads/{adId}`

Покупатель открывает карточку объявления, выбранного в шаге 1. Авторизация не требуется. Система возвращает полное содержимое карточки: заголовок, подробное описание, цену, категорию, город, статус, количество просмотров, дату создания и дату публикации. При каждом обращении к этому endpoint счётчик просмотров увеличивается на единицу.
